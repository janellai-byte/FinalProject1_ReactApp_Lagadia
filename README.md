# Conference Expense Planner

## Requirements
- Node.js (LTS recommended)
- Visual Studio Code

## Run the project
1. Extract `conference-expense-planner.zip`.
2. Open the extracted `conference-expense-planner` folder in VS Code.
3. Open **Terminal → New Terminal**.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL printed by Vite (usually `http://localhost:5173/`).

## Features
- Landing page and Get Started navigation
- Five room types with quantity controls and subtotals
- Five add-on types with quantity controls and subtotals
- Meal checkboxes and editable number of guests
- Automatically calculated grand total
- Show Details modal with an itemized cost table

The listed written requirements are used for the prices. Image URLs need an internet connection to display.
